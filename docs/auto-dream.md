# 自动复盘

同一工作目录积累一批未整理 Run 后，dsh-recall 会启动独立后台会话。打开左侧「复盘」，查看时间、状态、对话和轨迹。仅安装 dsh-recall 也可使用；复盘结论保存在插件自己的存储域中。

## 查看一次复盘

点复盘列表中的标题，进入宿主会话。这里显示 Agent 实际读取的材料、调用的工具和最后的说明。已完成会话可以继续交流；Agent 再次提交结论并正常结束回合后，修正才替换原结论。

点列表项的「详情」，查看固定材料范围、结论与来源，以及实际记忆写入。点来源，展开原始 Run 和消息。文件变化保留实际前后内容；失败或停止时已经发生的写入也会显示。

没有新增结论也有明确原因。出现“失败”，表示该批还未完成整理；不能据此推断没有发生文件变化。

## 控制运行

| 操作 | 行为 |
| --- | --- |
| 立即复盘 | 未达到自动门槛时也可运行；有多个目录时先选择项目 |
| 停止本次 | 取消当前后台工作，保留实际过程和文件变化；自动开关不变 |
| 暂停 | 暂停后续自动启动，当前工作继续；仍可立即复盘 |
| 恢复 | 恢复自动启动，仍遵守门槛和冷却间隔 |
| 重试 | 新建会话，沿用失败、取消或中断复盘的固定批次 |
| 刷新 | 重新读取状态；实时连接断开时重新连接 |

命令与界面使用同一个引擎：

```text
/dream status
/dream run
/dream stop
/dream pause
/dream resume
/dream retry <复盘 ID>
```

`/dream run` 使用当前会话的工作目录。设为 `autoDream: false` 只关闭自动启动；手动复盘仍可用。

## 保存到已有记忆目录

默认只保存复盘结论，不向系统提示词自动注入。Agent 可用 `dream` 工具回查这些结论。

需要长期 Markdown 记忆时，在插件设置中填写 `dreamMemoryDirectory`。例如：

```yaml
config:
  dreamMemoryDirectory: /Users/liuzhengdong/Obsidian笔记/AI 记忆
```

复盘会话先读取已有主题，再用专用工具合并。工具只接受配置目录内的 Markdown 文件，核对读取时的旧内容，并记录写入前后内容。它不修改 AGENTS.md、技能或系统提示词。每篇文件最多 64 KiB，每次复盘最多 20 次写入。

这个目录也可以由 simple-memory 等插件读取。若现有目录使用 frontmatter 或索引约定，保留原来的格式；dsh-recall 不负责其他插件的注入策略，也不要求安装它们。

停止或失败不会自动回滚文件。后续人工修改可能已经发生，因此第一版提供前后对照和修正入口，不恢复整个旧目录。

## 自动启动条件与模型

默认同一目录积累 30 条未整理 Run 后运行，每次最多整理最早的 30 条。同一宿主进程最多运行一次复盘，自动尝试之间至少间隔 1 小时。后台运行最长 10 分钟；进程退出或超时会中断，材料留待下次整理。

复盘只有在提交结构化结果、来源核对通过，并且该回合正常完成后，才推进进度。无新增结论但有明确原因也算完成。失败、取消和中断不推进进度。复盘自身及其后代会话不计入新材料。

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `autoDream` | `true` | 启用自动启动 |
| `dreamThreshold` | `30` | 每个工作目录的触发门槛，范围 1–1000 |
| `dreamProvider` / `dreamModel` | 空 | 同时留空使用宿主默认路由；同时填写指定模型 |
| `dreamMemoryDirectory` | 空 | 可选记忆目录，留空只保存复盘结论 |

`noSummary` 只控制 Run 摘要。它不会关闭自动复盘；若需要停止所有后台模型调用，同时关闭 `autoDream`。

## 数据与边界

复盘结果、目录进度、控制状态和会话归属存于 `dream` 存储域。原始 Run 仍由 `run_archive` 管理，原始消息正文仍由宿主管理。复盘结论区分事实、推断和未验证信息，并引用原始 Run 或消息。

删除 Run 不会自动删除已经提炼的结论或回滚记忆文件。需要纠正结论时，进入对应复盘会话说明修正；记忆文件按现有编辑方式修改。

左侧扩展使用宿主侧栏槽位。当前“任务 / 频道”来自 IM 插件，复盘会加入同一个页签容器；纯净宿主使用“任务 / 复盘”。IM 的共用页签约定属于插件间约定，未来升级若改变该接口，需要同步适配。

实现职责、失败恢复与接口依据见 [设计](specs/auto-dream.md)。
